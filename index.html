MS Drug Map

The following network displays several classes and examples of drugs that are currently used to treat Multiple Sclerosis. The specific drug names are displayed as smaller grey nodes of the network, and the edges connect them to the class of drug they belong to. Hovering over the drug name allows you to highlight the class(es) and doing the same with the drug class allows for better visualisation of the individual drugs belonging to selected class.
